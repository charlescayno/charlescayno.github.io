InnoMux2 Design Equations

True Physics Engine V5 Outputs

Current Limit: 3.75 A Primary Turns (NP): 36 Secondary Turns (NS): 5

1. Total Output Power (\\(P_O\\))

\\[ P_O = (V_{OUT(CV1)} \\times I_{OUT(CV1)}) + (V_{OUT(CVHV)} \\times I_{OUT(CVHV)}) \\] \\[ P_O = (20.00\\text{ V} \\times 0.100\\text{ A}) + (48.00\\text{ V} \\times 3.550\\text{ A}) = \\mathbf{172.40\\text{ W}} \\]

2. Reflected Output Voltage (\\(V_{OR\\_CVHV}\\))

\\[ V_{OR\\_CVHV} = (V_{OUT(CVHV)} + V_{Diode}) \\times \\frac{N_P}{N_S} \\] \\[ V_{OR\\_CVHV} = (48.0\\text{ V} + 1.0\\text{ V}) \\times \\frac{36}{5} = \\mathbf{352.8\\text{ V}} \\]

3. Minimum Peak Current Threshold (\\(I_{PEAK\\_MIN}\\))

Hardware limit: IC cannot output a pulse smaller than 26.5% of its typical current limit.

\\[ I_{PEAK\\_MIN} = I_{LIMIT\\_TYP} \\times 0.265 \\] \\[ I_{PEAK\\_MIN} = 3.75\\text{ A} \\times 0.265 = \\mathbf{0.994\\text{ A}} \\]

4. Minimum On-Time at No Load (\\(t_{ON\\_MIN\\_NL}\\))

\\[ t_{ON\\_MIN\\_NL} = \\frac{L_{P\\_TYP} \\times I_{PEAK\\_MIN}}{V_{DC\\_MAX}} \\] \\[ t_{ON\\_MIN\\_NL} = \\frac{456.8\\text{ \\mu H} \\times 0.994\\text{ A}}{860\\text{ V}} \\approx \\mathbf{0.528\\text{ \\mu s}} \\]

5. Maximum Switch Drain Voltage (\\(V_{DRAIN\\_PEAK}\\))

Engine assumes \\(V_{SPIKE} = 70.4\\text{ V}\\) based on transformer leakage inductance.

\\[ V_{DRAIN\\_PEAK} = V_{DC\\_MAX} + V_{OR\\_CVHV} + V_{SPIKE} \\] \\[ V_{DRAIN\\_PEAK} = 860\\text{ V} + 352.8\\text{ V} + 70.4\\text{ V} = \\mathbf{1283.2\\text{ V}} \\]

6. Synchronous Rectifier Peak Reverse Voltage (\\(SR\\_PRV\\))

For InnoMux2 single-winding, the SR diode sees the CV1 baseline voltage.

\\[ SR\\_PRV = V_{OUT(CV1)} + \\left( V_{DC\\_MAX} \\times \\frac{N_S}{N_P} \\right) \\] \\[ SR\\_PRV = 20.0\\text{ V} + \\left( 860\\text{ V} \\times \\frac{5}{36} \\right) = \\mathbf{139.4\\text{ V}} \\]

7. Operating Flux Density (\\(B_{MAX}\\))

Engine accounts for magnetic fringing flux with \\(F_{FRINGE} \\approx 1.06\\).

\\[ B_{MAX} = \\left( \\frac{L_{P\\_TYP} \\times I_{LIMIT\\_TYP}}{N_P \\times A_E} \\right) \\times F_{FRINGE} \\] \\[ B_{MAX} = \\left( \\frac{456.8\\text{ \\mu H} \\times 3.750\\text{ A}}{36 \\times 169.0\\text{ mm}^2} \\right) \\times 10^4 \\times 1.06 \\approx \\mathbf{2985\\text{ Gauss}} \\]

8. Peak Flux Density (\\(B_{PK}\\))

Worst-case startup/fault condition using maximum tolerance limits.

\\[ B_{PK} = \\left( \\frac{L_{P\\_MAX} \\times I_{LIMIT\\_MAX}}{N_P \\times A_E} \\right) \\times F_{FRINGE} \\] \\[ B_{PK} = \\left( \\frac{479.7\\text{ \\mu H} \\times 4.013\\text{ A}}{36 \\times 169.0\\text{ mm}^2} \\right) \\times 10^4 \\times 1.06 \\approx \\mathbf{3354\\text{ Gauss}} \\]
